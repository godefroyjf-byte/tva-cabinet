TVA CABINET 0.4.0 — PREMIER LANCEMENT SOUS WINDOWS

1. Installer Node.js 24 LTS : https://nodejs.org/
2. Extraire complètement le ZIP dans un dossier de votre ordinateur.
3. Dans le dossier extrait, double-cliquer sur DEMARRER.cmd.
4. Attendre l'ouverture du navigateur, puis cliquer sur « Importer des relevés PDF ».
5. Choisir un ou plusieurs PDF avec Ctrl/Maj, ou les glisser dans la zone prévue.
   Cliquer sur « Lire le PDF », comparer l'aperçu à l'original puis importer.
   Le document suivant est lu automatiquement ; vérifier chaque fichier séparément.
6. Pour votre déclaration trimestrielle : choisir « Trimestre »,
   puis le trimestre et l'année dans le tableau principal.

Importez le relevé entier, même si ses dates dépassent le trimestre.
Seules les dates TVA retenues dans la période choisie contribuent aux totaux
et à l'export. Les autres mouvements restent conservés et accessibles.

Garder la fenêtre de lancement ouverte pendant l'utilisation.
Pour arrêter : Ctrl+C dans cette fenêtre. Pour reprendre : DEMARRER.cmd.
Ne pas supprimer le dossier data : il conserve vos données.
Utiliser « Sauvegarder / restaurer » pour télécharger une sauvegarde complète.

Les PDF texte et scans lisibles sont traités localement, sans CSV obligatoire.
La reconnaissance de texte française est installée au premier lancement.
Internet est nécessaire pour cette installation, puis la lecture est hors ligne.
Limites : 10 Mo et 30 pages par PDF. Vérifier les dates, signes, soldes et lignes.
Lots : 20 fichiers et 50 Mo maximum. Les erreurs et doublons restent visibles.
Utiliser « Passer ce fichier » pour continuer, puis « Terminer » après le bilan.
Fermer la fenêtre conserve les fichiers déjà importés ; les autres restent à importer.
Le logo JG Avocat et le style du modèle de conclusions sont intégrés localement.
Les exemples de type Société Générale sont fictifs ; chaque relevé doit être contrôlé.
CSV, qualification, ventilation, export et sauvegarde sont aussi disponibles.
Excel et ajout de factures justificatives ne sont pas encore disponibles.

MISE A JOUR : sauvegarder dans l'ancienne version, l'arrêter avec Ctrl+C,
extraire cette version dans un nouveau dossier puis lancer DEMARRER.cmd.
Restaurer la sauvegarde si l'ancienne version contenait des données.
Conserver l'ancien dossier et sa sauvegarde jusqu'à vérification.
Le lancement et les parcours sont testés sous Linux. Le double-clic Windows
reste à vérifier sur votre poste. Le guide détaillé est dans README.md.
